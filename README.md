## Projets

### OpenCOLoRa — Course d'orientation connectée

Projet réalisé en équipe de 4 dans le cadre de ma formation d'ingénieur à Polytech Grenoble.

Développement d'une solution de course d'orientation combinant des balises embarquées, la technologie LoRa et une application web pour le suivi des participants.

**Fonctionnalités principales :**
- Communication sans fil longue portée via LoRa.
- Identification des participants par badge NFC.
- Enregistrement et transmission des passages.
- Application web de gestion des parcours et de suivi des résultats.

**Technologies :** C/C++, Python, React, FastAPI, MQTT, LoRa, NFC.
